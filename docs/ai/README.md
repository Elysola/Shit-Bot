# memecat：Discord 里的 AI 群成员

开启 `ai.enabled` 后，bot 在 Discord 里变成一个有固定人格的群成员（默认是猫娘 **memecat**）：被 @、被回复时说话，平时潜水观察，偶尔自己插一句；记得每个人说过的事，对不同的人态度不同，自己也有心情起伏。AI 只接入了 Discord，Telegram 端仍然只做推文推送。

## 功能一览

| 功能 | 说明 |
|---|---|
| 人格 | 人设卡定义名字、性格、说话方式、底线、不同好感下的态度、情绪基线与作息；设定集放世界观、群规、梗。改文件即时生效 |
| 对每个人的长期记忆 | 被动观察所有成员在所有可见频道的消息（不只是和 bot 聊天时），后台提炼成记忆；按用户 ID 存储，改名不丢 |
| 用户档案 | Discord 资料、发言统计、自我介绍、别人的转述、人际关系、bot 的反思；有权限时还有在线状态与正在玩的游戏 |
| 服务器记忆 | 群里的梗、规则、大事、话题、对 bot 的叫法 |
| 自我记忆 | bot 自己说过的观点、经历、承诺，让人格前后一致 |
| @ 解析 | `<@ID>`、角色、频道都解析成具体对象；回复只会提醒本轮出现过的人 |
| 历史回望 | 首次启动回望最近 30 天（每频道最多 5000 条），之后每次启动 / 重连补上停机期间的消息 |
| 好感度 | 6 档，由独立的"内心评估"模型站在人设立场判断；只影响语气和态度，从不展示数值 |
| 情绪 | 效价 × 唤醒度，有基线和作息曲线，随事件变化、随时间回归 |
| 主动插话 | 被叫到名字、有问题没人答、聊到感兴趣的话题等情况下自己插一句；有冷却、上限、反馈自适应 |
| 向量检索（可选） | 配了向量模型就做语义检索；不需要单独的向量数据库服务 |
| 隐私 | `/memory` 查看、`/forget` 删一条、`/optout` 不再记录、`/forget-me` 删除全部数据；保留期清理 |
